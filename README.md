# 📘 DPS104 - Ejemplos de Clase (Introducción)

Este repositorio contiene ejemplos prácticos desarrollados para la asignatura **Diseño y Programación de Software Multiplataforma (DPS104)**, enfocados en la introducción a conceptos básicos de programación y desarrollo web.

## 📂 Contenido del repositorio

Dentro de este proyecto encontrarás ejemplos utilizados en clase para reforzar los conceptos iniciales de programación, tales como:

- Introducción a la estructura de proyectos web
- Uso básico de HTML
- Introducción a React, Typescript y React Native
- Manipulación básica de variables y funciones
- Ejercicios guiados en clase
  

## 🛠️ Tecnologías utilizadas

- HTML5
- JavaScript
- TypeScript
- CSS (básico, si aplica)
- Editor de código (VS Code recomendado)
